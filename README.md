# OpenClaw 安装及问题解决指南

Windows 平台 OpenClaw 完整安装、配置、故障排查指南。

## 🚀 快速安装

**下载 [一键安装器](https://github.com/QijunLuo/openclaw-guide/releases/latest) 双击运行！**

或手动安装：
1. 下载 `start-openclaw.bat` 到桌面
2. 打开 `OpenClaw安装及问题解决.docx` 查看完整教程
