# OpenClaw 一键安装器

Windows 平台 OpenClaw 一键安装程序，自动完成 Node.js 安装 + OpenClaw 安装 + 基础配置。

## 🚀 快速安装

**[⬇ 下载 OpenClaw 一键安装器 (v2.1.1)](https://github.com/QijunLuo/openclaw-guide/releases/download/v2.1.1/OpenClaw-Installer.exe)**

双击运行，按提示操作即可。安装器会自动：
1. 安装 Node.js（如未安装）
2. 安装 OpenClaw
3. 完成初始化配置
4. 启动 OpenClaw Gateway
